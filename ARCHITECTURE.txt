Project Type: Enterprise Web Application
Taxonomy Category: enterprise_angularjs18
Build Tool: Angular CLI (v18)

Architectural Overview:
This application demonstrates an enterprise-grade modular architecture built with Angular 18.
- Lazy-Loaded Feature Modules: The core domain functionality is split into independent feature modules (DashboardModule, ReportsModule) that are loaded on-demand using Angular Router's `loadChildren` syntax.
- Scalability & Performance: By leveraging code-splitting at the feature level, initial bundle size is minimized while isolating domain boundaries for large-scale team development.
- Enterprise Layout: Features a global layout shell (`AppComponent`) with declarative routing (`router-outlet`) and deep linking support.
