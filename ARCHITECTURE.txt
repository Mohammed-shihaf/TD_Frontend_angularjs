Project Type: E-commerce Storefront Application
Taxonomy Category: ecommerce_angularjs18
Build Tool: Angular CLI (v18)

Architectural Overview:
This application implements an interactive E-commerce storefront architecture using Angular 18 features and reactive state management.
- Reactive State Management: Utilizes `CartService` powered by RxJS `BehaviorSubject` streams to manage shopping cart items, total quantities, and running order subtotals dynamically across components.
- Product Catalog Component (`ProductListComponent`): Displays a structured product list rendered from strongly-typed models, with direct integration to add items to the shared cart.
- Cart View Component (`CartComponent`): Renders live cart item quantities, calculated totals, and supports item removal or emptying the cart using async pipe subscriptions.
