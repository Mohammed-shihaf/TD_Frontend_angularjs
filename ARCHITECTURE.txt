Project Type: Progressive Web Application (PWA)
Taxonomy Category: pwa_angularjs18
Build Tool: Angular CLI (v18)

Architectural Overview:
This application implements a full Progressive Web Application using Angular 18 and `@angular/pwa`.
- Service Worker Integration: Configured via `@angular/service-worker` and `provideServiceWorker('ngsw-worker.js')` in `app.config.ts`.
- Web App Manifest: Includes `manifest.webmanifest` defining app name, theme color (#1976d2), display mode (standalone), and responsive icon sets in `public/icons/`.
- Asset & Route Caching: Defined in `ngsw-config.json` with automated asset group caching rules (app shell, index.html, JS/CSS bundles, static assets).
- Production Build Verification: `ng build` produces `ngsw.json` state manifest and `ngsw-worker.js` alongside app static bundles.
