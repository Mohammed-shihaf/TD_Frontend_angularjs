Project Type: Customer/Business Portal Application
Taxonomy Category: customerportal_angularjs18
Build Tool: Angular CLI (v18)

Architectural Overview:
This application implements a Customer Portal featuring authentication flow and route protection in Angular 18.
- Route Guards (`authGuard` / `CanActivateFn`): Protects sensitive route paths like `/account`. Unauthenticated access attempts are blocked and redirected to `/login` with return URL query parameters.
- Authentication State Service (`AuthService`): Manages customer authentication state via RxJS `BehaviorSubject` streams, supporting login, logout, and auth state checks.
- Section Gating: Renders public landing content (`HomeComponent`), login controls (`LoginComponent`), and gated customer portal profile features (`AccountComponent`).
