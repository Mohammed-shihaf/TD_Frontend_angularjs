# TD_Frontend_angularjs

Standalone Angular frontend — not connected to any backend or React
app by default. Separate from the TD_*_BE_nodejs_FE_reactjs_FE_angularjs
connected project-type repos, which combine backend+React+Angular together.

Each branch is `<project-type>_angularjs<version>` and carries that
project type's own real Angular logic, extracted standalone.

See ARCHITECTURE.txt on each branch for build commands and details.

Branches: 5 project types × Angular versions (16, 17, 18, 19).
